Install OpenJev on macOS with local Ollama qwen3:14b

This guide configures OpenJev to use an Ollama model already installed on your Mac. It avoids OpenJev's built-in model-download path and does not configure Hugging Face or cloud-model providers.

Important distinction: the first installation of Homebrew packages, Python dependencies, OpenJev source code, and the Ollama model normally requires internet access. Once everything is installed, inference can run locally. This guide does not promise that every dependency installer is network-free.

1. What you are setting up

  • OpenJev: a decision engine that returns structured choices, yes/no probabilities, or scores.
  • Ollama: runs the model locally on your Mac.
  • Model: qwen3:14b, downloaded once into Ollama's local model store.
  • Local endpoint: OpenJev connects to http://localhost:11434/v1, not to a hosted model provider.

OpenJev is not a conventional free-form chat interface. Its main interface is for structured decisions.

2. Check your Mac

Open Terminal and run:

uname -m
sw_vers

On Apple Silicon, uname -m should print arm64. The 14B model can require substantial unified memory; performance depends on your Mac's RAM, model quantization and other running applications. If the model does not fit comfortably, use a smaller model rather than assuming it will run well.

3. Install Ollama and download the model once

Install Ollama from its official website, then open the Ollama app:

https://ollama.com/download/mac

In Terminal:

ollama pull qwen3:14b
ollama list

The first command downloads the model into Ollama. This is an Ollama model pull, not OpenJev downloading model files from Hugging Face.

Check that Ollama responds locally:

curl http://localhost:11434/api/tags

You should see the locally installed model in the response. You can also test the model directly:

ollama run qwen3:14b

Type a short test prompt, then enter /bye to exit.

4. Install OpenJev

Install the tools needed to retrieve the source and manage its Python environment. If you already have Homebrew and uv, skip the corresponding install steps.

Homebrew: https://brew.sh/

brew install git uv

Clone the OpenJev project:

git clone https://github.com/lookski/openjev.git
cd openjev

Install the project in its local virtual environment:

uv sync

If the repository's current README specifies an extra for the Ollama/API-compatible backend, follow that project's current installation instructions. Do not run OpenJev's built-in local-model setup or Hugging Face model download commands for this configuration.

5. Run OpenJev using only local Ollama

First ensure the Ollama app is running and ollama list shows qwen3:14b.

Use OpenJev's explicit Ollama backend and model setting rather than its interactive provider-selection wizard:

uv run openjev-easy --backend ollama --model qwen3:14b

The documented Ollama-compatible endpoint is http://localhost:11434/v1. If your OpenJev version asks for a base URL, use:

http://localhost:11434/v1

Do not enter an OpenAI, OpenRouter, Jev cloud, or other remote API key. Do not select a remote backend.

For a one-shot test, the project documents this pattern:

uv run openjev-easy --backend ollama --model qwen3:14b --once "The server is down and customers cannot log in."

The exact command options can change between OpenJev revisions. If a flag is rejected, check the locally installed command's help:

uv run openjev-easy --help

6. Verify the local-only configuration

Before sending any real data:

  1. Confirm ollama list shows qwen3:14b.
  2. Confirm the configured backend is ollama.
  3. Confirm the base URL, if shown, is http://localhost:11434/v1.
  4. Leave API keys for cloud providers unset.
  5. Do not choose OpenJev's local backend if that version's local backend automatically fetches model weights; use the explicit ollama backend.
  6. If you need a stronger guarantee, disconnect Wi-Fi after installation and model download, then run a test. If a command fails because it tries to reach a remote service, stop and inspect its configuration rather than switching to an online provider.

7. Start offline after setup

After all packages and the model are installed, start Ollama and run OpenJev while disconnected from the internet:

ollama run qwen3:14b

In another Terminal window, from the OpenJev repository:

uv run openjev-easy --backend ollama --model qwen3:14b

Use Ctrl+C to stop the OpenJev process. Local inference should continue to work without internet as long as all required software and model files are already present.

8. Tests and Comparing the Normal LLM to OpenJEV

Under openjev/demo folder, please run the demo

python3 explain.py

Under openjev/demo folder, please run the tests and comparing demos

python3 compare.py

Troubleshooting

ollama command not found

Open the Ollama app or install it from https://ollama.com/download/mac, then reopen Terminal.

Model not found

Run:

ollama list
ollama pull qwen3:14b

The pull requires internet if the model is not already cached.

Connection refused at port 11434

Make sure Ollama is running, then test:

curl http://localhost:11434/api/tags

OpenJev prompts for a provider or API key

Exit the wizard and run the explicit command with --backend ollama --model qwen3:14b. Never select a cloud backend for this local-only setup.

It is slow or runs out of memory

Close memory-heavy applications and retry. A 14B model is relatively large; smaller Macs may perform better with a smaller model.
