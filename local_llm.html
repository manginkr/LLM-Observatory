Ollama + Qwen3:14B + Open WebUI on macOS

Run a local language model on your Mac and chat with it in your browser.

  • Runtime: Ollama
  • Model: qwen3:14b (about 9.3 GB to download)
  • Web interface: Open WebUI in Docker
  • Local URLs: Ollama API at http://localhost:11434; WebUI at http://localhost:3000
Hardware note: qwen3:14b is a quantized model, not a 14 GB download. Allow at least 15–20 GB of free disk space for the model and working room. A Mac with 16 GB unified memory may run it, but 24 GB or more is more comfortable, especially with other apps open. Performance depends on your Mac. Apple Silicon is recommended; Intel Macs run Ollama on CPU and may be much slower.

1. Requirements

  • macOS 14 Sonoma or newer (check the current Ollama macOS requirements)
  • Internet connection for the initial downloads
  • Docker Desktop for Mac
  • Administrator rights to install apps
  • Ideally 24 GB+ unified memory and 15–20 GB free storage

Check your Mac model and memory: Apple menu → About This Mac.

2. Install Ollama

  1. Open the official download page: https://ollama.com/download
  2. Download the macOS app, open the .dmg, and drag Ollama into Applications.
  3. Launch Ollama from Applications. Approve any macOS prompts and allow it to install its command-line tool if prompted.
  4. Open Terminal and verify:
ollama --version

If ollama is not found, quit and reopen Terminal after launching Ollama. Check the official macOS instructions: https://github.com/ollama/ollama/blob/main/docs/macos.mdx.

3. Download and test Qwen3:14B

In Terminal, run:

ollama pull qwen3:14b

This downloads the model (currently about 9.3 GB; size can change). Then start a chat:

ollama run qwen3:14b

Try a prompt, for example:

Explain how local language models work in simple terms.

Type /bye to leave the model chat. Check that the model is present:

ollama list

Official model page: https://ollama.com/library/qwen3:14b.

4. Install Docker Desktop

  1. Download Docker Desktop for Mac: https://www.docker.com/products/docker-desktop/
  2. Install and launch it.
  3. Wait until Docker Desktop says it is running.
  4. Verify in Terminal:
docker --version
docker info

If docker info errors, start Docker Desktop and try again.

5. Start Open WebUI

Ollama runs directly on macOS; Open WebUI runs in a Docker container. This is a straightforward local setup.

5.1 Create a persistent secret key

Generate a secret:

openssl rand -hex 32

Copy the output into a password manager or a safe local note. You will use the same value when recreating/updating the container. Do not publish it or commit it to a repository.

5.2 Run the WebUI container

Replace PASTE_YOUR_SECRET_HERE with the generated value, then run:

docker run -d \
  --name open-webui \
  --restart unless-stopped \
  -p 127.0.0.1:3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data \
  -e WEBUI_SECRET_KEY='PASTE_YOUR_SECRET_HERE' \
  ghcr.io/open-webui/open-webui:main

Notes:

  • The open-webui volume preserves chats and settings across container replacements.
  • Binding to 127.0.0.1 keeps the web interface accessible only from this Mac by default.
  • Keep the same WEBUI_SECRET_KEY when recreating the container, or existing sessions may be invalidated.
  • The main image is updated over time. For a more reproducible setup, use a specific stable version tag from the official documentation.

Check startup logs:

docker logs -f open-webui

Wait for startup to complete, then press Ctrl+C to stop following the logs (this does not stop the container).

Official setup guide: https://docs.openwebui.com/getting-started/quick-start/.

6. Open the chat interface

  1. Make sure Ollama is running on the Mac and the model has been downloaded.
  2. Open http://localhost:3000 in your browser.
  3. Create the first Open WebUI account. On a new instance, the first account is typically the administrator.
  4. Start a new chat and choose qwen3:14b from the model selector.
  5. Send a test prompt.

If the model does not appear, open Admin Settings → Connections and verify the Ollama connection. With the Docker command above, Open WebUI should reach Ollama at:

http://host.docker.internal:11434

Do not use localhost:11434 inside the container; there, localhost refers to the container itself.

7. Quick health checks

Check Ollama's API

curl http://localhost:11434/api/tags

The output should include qwen3:14b.

Check the WebUI container

docker ps
docker logs --tail 100 open-webui

Test model generation without the browser

curl http://localhost:11434/api/chat \
  -H 'Content-Type: application/json' \
  -d '{
    "model": "qwen3:14b",
    "messages": [
      {"role": "user", "content": "Reply with: Local model is working."}
    ],
    "stream": false
  }'

8. Common issues

Model download is slow or fails

  • Check your internet connection and available disk space.
  • Retry with ollama pull qwen3:14b.
  • Keep the Mac awake until the download finishes.

WebUI says no models are available

  • Confirm Ollama works with ollama list.
  • Confirm the API responds: curl http://localhost:11434/api/tags.
  • In Open WebUI, verify the Ollama URL is http://host.docker.internal:11434.
  • Restart the WebUI container after checking its logs:
docker restart open-webui

Port 3000 is already in use

Change the left side of the port mapping, for example -p 127.0.0.1:3001:8080, then open http://localhost:3001. If the container already exists, remove/recreate it (your named volume will preserve data).

Model runs slowly or the Mac becomes hot

  • Close memory-heavy apps.
  • Start with shorter prompts and avoid very long conversations.
  • If performance is not acceptable, try a smaller model such as qwen3:8b:
ollama pull qwen3:8b
ollama run qwen3:8b

Container won't start

docker logs --tail 200 open-webui
docker ps -a

9. Start, stop, and update

Stop / start WebUI

docker stop open-webui
docker start open-webui

Ollama can be quit from the macOS menu bar app; launch it again when needed.

Update Open WebUI

The following replaces the container but keeps the open-webui data volume. Use the same secret key as before:

docker pull ghcr.io/open-webui/open-webui:main
docker rm -f open-webui
docker run -d \
  --name open-webui \
  --restart unless-stopped \
  -p 127.0.0.1:3000:8080 \
  --add-host=host.docker.internal:host-gateway \
  -v open-webui:/app/backend/data \
  -e WEBUI_SECRET_KEY='PASTE_THE_SAME_SECRET_HERE' \
  ghcr.io/open-webui/open-webui:main

Update Ollama through the Ollama app/download page. Update the model separately if desired:

ollama pull qwen3:14b

Remove WebUI

This removes the container but keeps saved chats/settings in the named volume:

docker rm -f open-webui

To permanently delete WebUI data as well, run this only if you are sure you no longer need it:

docker volume rm open-webui

To remove the model and reclaim its disk space:

ollama rm qwen3:14b

10. Privacy and network notes

  • Model inference runs locally, but initial downloads require the internet.
  • Keep the WebUI bound to 127.0.0.1 unless you intentionally want other devices to access it.
  • Do not expose Ollama's port (11434) or Open WebUI to the public internet without a deliberate, secured network design.
  • If you enable web search, external APIs, or cloud models in Open WebUI, those features can send data outside your Mac. A local model by itself does not require sending prompts to a model provider.
  • Create an Open WebUI login and keep the secret key private.
