Over the past few weeks, I’ve been diving deep into the world of privacy-focused, local AI infrastructure. Like many, I started by relying entirely on cloud-based LLM APIs, but I wanted to explore what it takes to run powerful models entirely on local hardware—keeping data private, offline-capable, and completely under my control.

To document what I’ve learned (and help others skipping the trial-and-error phase), I built and deployed a lightweight static site using GitHub Pages and Bootstrap 5: [https://github.com/manginkr/LLM-Observatory]

What you'll find on the site: Local ChatGPT-Style Setup: A step-by-step guide to running Ollama and Qwen3:14B paired with Open WebUI in Docker on macOS.

Structured Decision-Making with OpenJev: How to configure OpenJev to connect directly to local Ollama endpoints for structured choices and probability scores instead of just open-ended chat.

Modular Static Architecture: Built cleanly with modern Bootstrap 5 and reusable component patterns.

It’s been a rewarding journey moving from cloud dependence to fully localized, offline-ready workflows. If you're curious about running local AI or exploring decision engines like OpenJev, check it out!
